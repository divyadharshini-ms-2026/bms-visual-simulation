🔋 Battery Management System (BMS) Visual Simulation

📌 Project Overview

This project is an interactive web-based Battery Management System (BMS) simulation developed to demonstrate battery monitoring and basic fault-detection logic.

The dashboard displays simulated battery voltage, current, power, temperature, and State of Charge (SOC). Users can adjust the input values and test simulated fault conditions through interactive controls.

🎯 Objectives

- Monitor simulated battery parameters.
- Calculate electrical power using the formula P = V × I.
- Demonstrate low-voltage and high-voltage warnings.
- Simulate overcurrent and over temperature conditions.
- Display battery State of Charge (SOC).

✨ Features

- Interactive battery dashboard.
- Adjustable battery input sliders.
- Real-time power calculation.
- Simulated fault warnings.
- Voltage monitoring graph.
- Responsive web interface.

▶️ How to Use

1. Open the live demo.
2. Adjust the voltage, current, temperature, or SOC sliders.
3. Use the fault simulation buttons to trigger warnings.
4. Observe the displayed readings and protection status.
5. Press Reset to restore the default values.

⚠️ Limitations

This is an educational software simulation. It does not measure real battery parameters or provide physical battery protection. The thresholds are illustrative and must not be used to protect an actual battery.
